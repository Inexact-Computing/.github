## Overview

- **Topic**: Inexact and Approximate Computing arithmetic hardware & research literature
- **Total papers**: 600+ curated catalog entries
- **Modality**: Structured bibliographic database (`papers.json`), static org homepage (`profile/README.md`), and client-side web application (`docs/index.html`)
- **Learning**: Public curriculum in [inexact-learn-public](https://github.com/Inexact-Computing/inexact-learn-public)
- **Research domains**: Approximate Multipliers, Adders & Dividers, CORDIC & Trigonometry, Quality-Configurable Systems, and DNN/DSP Workloads
- **Deployment**: Zero-dependency static site hosted on GitHub Pages from `/docs`

| Path | Role |
